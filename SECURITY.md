# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, please report it responsibly.

- **Email:** security@jordannewell.com
- **GPG key fingerprint:** `67567DC5E7C5353F85F2AF0DAC05D3F3E0EFA32A`
- **Acknowledgment:** Reports are acknowledged within 72 hours.

Please encrypt your report using the GPG key above whenever possible. Include enough detail for us to reproduce and assess the issue.

## Scope

This policy covers security issues in:

- Shell scripts (`bashrc`, `install.sh`, `bin/`, `scripts/`)
- PowerShell profiles and setup (`powershell/`, `install.ps1`, `setup.ps1`)
- Configuration files (`.gitconfig`, `.editorconfig`, `.config/`)

Out of scope: feature requests, style issues, and non-security bugs — open a regular issue for those.

## Preferred Languages

Reports accepted in English.
